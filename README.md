# shigerix_cos
コスプレを便利にするあれやそれ

## コスポーズ（ポージング・立ち位置 共有ツール）
スマホで、コスプレ撮影のポージングや人物の立ち位置を棒人形で作り、**リンクで共有**できる静的Webアプリ。

**公開URL**: https://shigerix.github.io/shigerix_cos/

### 使い方
- **＋人形**: 棒人形を追加（何体でも）。
- **人形をタップ**: 選択。下部の**プリセットポーズ**で一括変更、**関節の丸をドラッグ**で自由に微調整。
- **ドラッグ**: 人形を好きな位置へ移動。
- **📐 構図**: 縦／横／正方の比率を切替。
- **🖼 背景**: 内蔵プリセット、または画像をアップロードして選択（アップロード画像はこの端末のブラウザ内にのみ保存）。
- **🔗 共有**: 現在の配置をURLに埋め込みコピー。開くと同じ配置が再現されます。
  - ※ アップロード背景は容量の都合でURLには含まれません（内蔵プリセット背景は含まれます）。

### 技術
- 素の HTML / CSS / JavaScript（ESモジュール）＋ SVG。ビルド不要。
- 棒人形は関節角度（Forward Kinematics）で表現。共有はシーンをURLハッシュにエンコード。
- 自動保存: 現在のシーンは `localStorage`、アップロード背景は `IndexedDB`。

### ローカルで動かす
```
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

### デプロイ
`main` への push で GitHub Actions（`.github/workflows/deploy.yml`）が Pages へ自動デプロイ。
初回のみ GitHub リポジトリの **Settings → Pages → Source** を **「GitHub Actions」** に設定してください。
